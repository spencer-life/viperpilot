# Viper Mouse Utility

This repository is a sanitized public starting point for development of the Viper mouse utility. The product name is provisional.

Its GitHub Actions checks are hardware-free; they validate source and tests without connecting to or writing to a mouse. Historical device measurements and diagnostics are deliberately not published here; their absence does not prove hardware support.

Hardware support and writes must follow the evidence gates in `AGENTS.md` and `ROADMAP.md`, with new recorded evidence.
